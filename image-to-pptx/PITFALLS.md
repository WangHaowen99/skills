# 渲染器与格式的坑

**回看**时图形不对，先查这里。每条都是实际踩过、只在渲染图上才现形的——XML 合规、PowerPoint 正常，所以不渲染永远发现不了。

## 图形没渲染出来

| 现象 | 原因 | 处置 |
|---|---|---|
| 图标只剩圆和直线，缺一半 | 自由曲线（`a:custGeom`）放进了 `p:grpSp`，QuickLook / 预览 / Keynote 会整组吞掉 | **图标绝不编组**。代价是形状数多，编辑性不受影响 |
| 闪电 / 齿轮 / 云整个不见 | `lightningBolt`、`gear6`、`cloud` 等复杂预置几何 QuickLook 不渲染 | 改用 `poly()` 手绘。`verify.py` 会报这类几何 |
| 曲线画出来了，箭头没了 | `a:tailEnd` 挂在 custGeom 开放路径上，QuickLook 不给 custGeom 渲染 line-end | 用 `bez()`——它另画一个实心三角，并把折线提前 10px 收住。**直线连接符走 `prstGeom`，原生箭头正常**，不受影响 |
| 箭头只剩半截色块 | z-order：先画箭头后画面板，卡片盖住了它 | 跨面板箭头放在所有面板之后 |
| 长线横穿表格 | 同上，反了——源图里这段是被表格盖住的 | 拆成表格上下两段，或在表格之前画 |
| 两块同色形状拼接处有一道色差 | QuickLook 把 `roundRect` 的填充渲染得比 `rect` 浅一档（#F2 → #F5） | 只圆部分角时用 `rshape` 画单个自由形状，不要「圆角矩形 + 方块压角」 |

## 文字

| 现象 | 原因 | 处置 |
|---|---|---|
| 字体下方红色波浪线 | 拼写检查。`lang` 只是辅助，`noProof="1"` 才是开关 | `style_run()` 已逐 run 设好；绕开它直接 `add_run()` 的地方要自己补 |
| 中文变成别的字体 | 只设了 `a:latin`。中文走 `a:ea` 槽位，漏了就回落 | 四个槽位 `latin`/`ea`/`cs`/`sym` 全写 + 主题 `majorFont`/`minorFont`。`style_run()` 和 `save()` 已覆盖 |
| 设了不换行还是折行 | `word_wrap=False` 不是所有渲染器都认；CJK 顿号处仍可能断行 | 不要依赖它，**把字号调到真能放下** |
| 本机预览字重字宽不对 | macOS 通常没装微软雅黑，回落到苹方，宽 7~12% | 属预期。pptx 里字体名正确，Windows Office 打开即对。估宽按 1.1 留余量 |
| 长标题把下一行压住 | 单行文本超宽被折成两行，第二行落到下一个元素上 | 降字号或加宽文本框，重渲染确认 |
| 竖排轴名在预览里横着折成一列 | QuickLook 不画旋转文字（只按旋转后的外框排版），`vert270` 也不认 | PowerPoint / WPS 正常，属预期；不要为了预览改结构，交付时说明 |
| 小圆里的编号数字偏下、被裁 | 椭圆的内切文字区放不下一行，QuickLook 把字压到下沿 | `numc` 已改为圆 + 独立文本框 |
| 大字号混排的一行整体往下偏 | 文本框比最大字号的行高还矮，居中时多出的部分往下溢 | 文本框高度至少盖住最大字号行高（约 1.3 × 字号换算成像素）；72pt 大数字要约 150 px 高 |
| 全圆角胶囊里的字偏下、被裁 | 圆角半径到半高时，roundRect 的内置文字区被压扁 | 用 `chip`：形状和文字分开画 |
| ▲▼ 徽标折行 | ▲▼ 实际渲染接近一个汉字宽，`wpx` 按半宽估偏窄 | `badge_width` 按一个汉字算 |
| 短连线两头的箭头叠成菱形 | 层间距只有二十几像素，中号箭头太大 | 短连线用小号箭头（`w="sm" len="sm"`） |
| 编号落在两个格子的缝上 | 编号圆心压在格子左上角，一半出界 | 编号压在格子上沿、往里收 12 px |

## 表格

表格一律用原生表格（`grouped_table` / `native_table`）。拼文本框看着一样，用户一编辑就散——这是用户明确提过的问题。

| 现象 | 原因 | 处置 |
|---|---|---|
| 行被撑高，表格溢出页面 | 空单元格（含合并后被隐藏的格）的段末标记默认 18pt，按 18pt 算行高 | `table_endpara` 给每格每段补段末字号 |
| 预览里行高仍比设定高 | QuickLook 忽略单元格边距（按默认 0.05in 上下边距），行高 ≈ 默认边距 + 行数 × 行距 | `cell_set` / `cell_lines` 写固定行距（字号 + 2pt 左右）；PowerPoint 按设定行高排，预览偏高属预期 |
| 想要的表头色变成蓝色、隔行底纹 | python-pptx 新建表格默认套「中度样式 2」 | `native_table` 已换成无样式表格，底色和框线逐格显式写 |
| 框线在合并格里出现断线 | 合并区域内部格子也各有框线 | `grouped_table` 按分组边界统一计算每格四边框线 |

## 格式与工具

- **`RGBColor` 是 `tuple` 子类**，可直接下标取 r/g/b，`mix()` 靠这个混色。
- **`rrect` 的圆角**用 `adjustments[0] = radius / min(w, h)`，超过 0.5 会被钳住。
- **头部只圆上面两角**：先画整块圆角矩形，再叠一个同色方块压平下半。
- **qlmanage 只渲染第一页**，多页 deck 必须单页单独构建（`preview.py` 做的就是这件事）。
- **导入顺序会改配色**：`icon_lib` 带着 `deck_kit` 的中性配色（RED = #E05252），`from icon_lib import *` 放在 `draw_kit` 之后会把复刻风的红色覆盖掉。直接 `from components import *`，它已按正确顺序导入。
- **git 会转义 CJK 文件名**，`git ls-files | grep '\.pptx$'` 搜不到中文名的 pptx，要按目录列。

## 坐标约定

坐标写**源图像素**，`X()`/`Y()` 换算到 EMU。不同 deck 的像素稿尺寸不一样（1673×951、1700×956、1663×944 都出现过），**别互相套用**——每页模块里用 `CANVAS` 声明自己的尺寸。

幻灯片恒为 16:9（13.333×7.5in）。源图比例与 16:9 差一点时纵向会被轻微压缩，1% 以内不可察；差得多就要改画布或接受留白。
