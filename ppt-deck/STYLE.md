# 默认样式规范

用户另有要求时以用户的为准。

默认按**阅读型**材料设计（发送阅读、打印、近距离投屏）。**宣讲型**（大会场投屏）：正文 ≥14pt，每页内容区 2–3 个区块，其余照旧。

## 一、页面框架

| 项 | 规定 |
|---|---|
| 画布 | 16:9 宽屏，33.87 × 19.05 cm |
| 页边距 | 左右 1.0 cm，上 0.6 cm，下 0.8 cm |
| 标题区 | 距顶 0.6 cm 起，高 1.6 cm；左对齐，文本框顶端对齐；每页位置固定；标题下不加分隔线 |
| 内容区 | 标题区下方 0.3 cm 起，至距底 1.0 cm 止，约 31.9 × 15.5 cm |
| 页脚 | 左下数据来源／注释，右下页码；有密级要求时放页脚中间 |
| 区块间距 | 全页统一 0.3 cm |
| 块内边距 | 左右 0.2 cm，上下 0.15 cm |

## 二、字体、字号、颜色

### 字体

中文微软雅黑，西文和数字 Arial。PowerPoint 字体对话框里「西文字体」「中文字体」两项都要设。

### 字号

| 元素 | 字号 | 样式 | 颜色 |
|---|---|---|---|
| 页面标题 | 20pt | 加粗 | #C7000A |
| 重点突出文本 · 左侧标签 | 12pt | 加粗 | 白 |
| 重点突出文本 · 右侧正文 | 12pt | 常规，关键词加粗 | #333333 |
| 区块标题 | 12pt | 加粗，居中 | #333333 |
| 正文 | 11pt（可在 10.5–12pt 间调） | 常规 | #333333（次要说明 #595959） |
| 表头 | 11pt | 加粗 | #333333 |
| 表格内容 | 10.5pt | 常规 | #333333 |
| 架构图模块、时间轴说明 | 10pt | 常规 | #333333 |
| 指标卡数字 | 24pt | 加粗 | #C7000A |
| 图表坐标轴、数据标签 | 9pt | 常规 | #7F7F7F |
| 脚注、数据来源、页码 | 8pt | 常规 | #7F7F7F |

除图表标注和脚注外，不小于 10pt。

### 色板

全篇只用下列颜色，整体是**浅色系**：图形和底色不用黑色，也不用 #404040 及更深的灰；焦点用红，其余用中浅灰。

| 色值 | 用途 |
|---|---|
| #C7000A | 标题、红色标签底、强调文字、重点边框、当前节点、主线 |
| #E6A5A8 | 图表第四色、瀑布图分项柱 |
| #FBECED | 浅红底：焦点层、重点行、缺口、涨跌徽标底 |
| #333333 | 重点文字、正文 |
| #595959 | 次要文字 |
| #7F7F7F | 刻度、脚注、说明 |
| #8C8C8C | 最深的图形色，只用于细线细条（如子弹图实际值条） |
| #A6A6A6 | 轴、骨架线、普通箭头、哈维球、时间轴主轴、已完成节点 |
| #BFBFBF | 已完成实心块、模块边框、表格框线、分隔线 |
| #D9D9D9 | 架构图层名侧边栏、战略屋横梁 |
| #E6E6E6 | 表头底、进度条轨道、网格 |
| #E7E6E6 | 重点突出文本右侧底 |
| #F2F2F2 | 文字块、表格首列、指标卡底 |

- 文字保留 #333333 / #595959：9–10pt 小字再浅，投屏和打印都看不清。
- 实心灰块上一律配深字，白字只用在红底上。
- 图表系列按 #C7000A → #A6A6A6 → #D9D9D9 → #E6A5A8 取色；重点系列用红，其余用灰。

### 强调

- 加粗：关键词、要点小标题
- #C7000A：关键数字、结论性短语
- 除标题和红色标签外，每页标红 ≤5 处，每个文字块 ≤2 处
- 不用下划线、斜体、荧光底色

### 形状与线条

- 一律直角；不加阴影、渐变、3D、发光
- 模块边框 0.75pt #BFBFBF；表格框线、分隔线 0.5pt #BFBFBF；普通箭头 1pt #A6A6A6；重点路径箭头 1.5pt #C7000A
- 最终 pptx 里全部内容可编辑（文本框、形状、原生表格和图表），不直接贴位图；AI 生成的图可用 `image-to-pptx` 复刻成原生形状

## 三、标题

「必须有观点」见 SKILL.md 铁律，这里只管格式。

| 项 | 规定 |
|---|---|
| 样式 | 微软雅黑 20pt 加粗 #C7000A |
| 句式 | 「主题：观点」，主题 2–8 字 |
| 长度 | ≤40 字（英文、数字两个算一个字），最多两行；超长改写，不缩字号 |
| 观点数 | 一页一个核心观点；有两个时须是因果或递进关系 |
| 依据 | 标题里的每个判断都能在本页正文找到依据 |
| 禁用 | 没有对象、没有数字的空泛词：赋能、全面提升、持续优化 |

### 范例

- ✓ `Agentic RL：训练决定Agent效果上限，超长序列优化与并行调度决定训练性能`
- ✓ `多模态趋势：头部客户单任务规模与总空间双增长，长序列/RL/统一多模态成共性需求`
- ✗ `自动驾驶：围绕ADS等重点客户依托图下沉、算子融合等方案持续优化模型性能`——只写做了什么，没有结论
- ✓ `自动驾驶：图下沉+算子融合使ADS模型端到端时延下降XX%，已在N家重点客户落地`——XX、N 用真实数据

## 四、内容组件

稿里引用组件时写编号（C1–C7），样式按本节，不在稿里重复。

### C1 · 分层架构图

讲「系统由什么组成」：自上而下分层，上层依赖下层，位置本身表达依赖关系，层内不画箭头。落 pptx 用排版引擎 `arch_diagram`：规格里只写层、模块、容器、状态和连线，坐标、对齐、箭头位置、图例都按下面的规则算出。

**元素（23 种）**

| 类 | 元素 |
|---|---|
| 结构 | 层带、层名栏、焦点层（浅红底）、层标题、行标签、系统边界框（虚线）、跨层贯通栏（安全、运维这类贯穿各层的能力） |
| 内容 | 模块（图标 + 文字 + 副文字）、容器（一个实现或子系统）、容器分组（如已具备 / 待补齐）、能力标签、占位容器（其他实现……） |
| 状态 | 重点（红实线框）、缺口（红虚线框）、新增（NEW 角标）、规划中（灰虚线）——模块、容器、标签通用 |
| 外围 | 使用者行（边界上方）、外部依赖行（边界下方，虚线）、注释栏（右侧，放「迁移不改动」这类说明，不混进模块网格） |
| 标注 | 编号（红圆，压在元素上沿、往里收，归属不和相邻元素混淆）、图例（只列图里实际用到的状态） |
| 连线 | 层间箭头（可对齐到指定模块中线）、关键路径（红色单向）、分发线（横线 + 下行箭头对齐各容器中线，说明压在横线上并自动避开箭头） |

**栅格**（1 cm ≈ 49 px，按 33.87 cm 宽画布）

| 项 | 规定 |
|---|---|
| 层名栏 | 宽 1.6 cm，层名 2–5 字，放不下自动拆两行 |
| 间距 | 层内边距 0.2 cm，模块间距 0.16 cm，层间距 0.5 cm（带分发线 0.9 cm） |
| 行高 | 模块行 0.9 cm；容器标题 0.6 cm、每行能力标签 0.57 cm |
| 层高 | 按内容算出，不手调 |
| 模块宽 | 同一行**等宽铺满**；行标签占的列在本层所有行都预留，保证上下对齐 |
| 容器宽 | 按所含标签列数比例分配；同层容器等高 |
| 跨层栏 / 注释栏 | 宽 2.1 cm / 2.2 cm |
| 对齐 | 各层模块区左右边缘严格对齐 |

**限额与强调预算**

- 3–5 层，每层最多 2 行；每行建议 ≤6 个模块，硬上限 8；模块名建议 ≤6 字，硬上限 8。
- 焦点层最多 1 个；重点元素不超过总数的 1/4 且最多 3 个；编号最多 6 个，不重复、不跳号。
- 文字放不下时依次：降半号（不低于 9pt）→ 换两行 → 报错要求改文案，**不缩到看不清**。
- 同一张图里模块要么都带图标、要么都不带；图标统一红色线性。

**两档密度**：完整版（带图标模块、容器、外围行、注释栏），用于架构是页面主体；精简版（每层一行文字 + 一排引擎卡），用于架构是配角。

**自动体检**（排版引擎出图时给出）：文字放不下、每行模块数和字数超限、重点超预算、焦点层超过 1 个、编号重复或跳号、层数超出建议。

### C2 · 表格

- **规模**：3–4 列，数据行 ≤8 行
- **表头**：#E6E6E6 底，#333333 11pt 加粗，居中
- **数据行**：白底，10.5pt #333333；对比表的首列是「对比维度」，#F2F2F2 底加粗
- **框线**：所有单元格 0.5pt #BFBFBF
- **对齐**：文字左对齐；数字、✓/×、高/中/低等短值居中；一律垂直居中
- **强调**：关键单元格文字 #C7000A 加粗，每表 ≤3 处；不用整行底色强调

### C3 · 文字块

- **外观**：#F2F2F2 底，无边框，直角
- **块标题**：12pt #333333 加粗，居中，置于块顶，与正文间距 0.15 cm
- **正文**：11pt #333333，左对齐，1.1 倍行距；一级要点用 #C7000A 小方块「■」，二级用 #595959「–」，最多两级
- **条数和写法**：每块 3–5 条，每条 ≤2 行；统一写成「**关键词：**说明」
- **配图**：讲流程或结构时，块内可放 1 个 C4 示意图，放在块标题下方或正文右侧，高度 ≤块高 1/3
- **并排**：多块并排时等宽等高，标题在同一水平线上

### C4 · 示意图与图标

- **图标**：优先用 PowerPoint「插入 → 图标」里同一套线性图标；主体 #808080（中灰），每个图标最多一处 #C7000A 点缀
- **示意图**：用矩形、圆、箭头、连接线等基本形状拼成
- **禁用**：照片、3D、渐变、emoji、卡通人物、网络剪贴画、不同风格图标混用

### C5 · 数据图表与指标卡

**按用途选图**

| 要表达的 | 用 |
|---|---|
| 单个关键数字 | 指标卡 |
| 类别比较 | 柱状图或条形图 |
| 变化趋势 | 折线图 |
| 构成比例（≤5 类） | 堆叠条形图或环形图 |
| 多维评估（4–6 维，且有对照对象） | 雷达图 |
| 完成率、达成率 | 半圆仪表盘，每页 ≤3 个 |

- **指标卡**：#F2F2F2 底；数字 24pt #C7000A 加粗，单位 12pt，说明 10pt，同比／环比 9pt；多张并排等宽
- **前后对比指标卡**：一行「旧值 → 新值」，旧值 #8C8C8C 加粗，新值 #C7000A 加粗、比旧值大约 1.2 倍，单位与新值同色；说明一行放在下方。适合「改进前后」类结论，同页 2–4 张竖排或横排
- **统计条**：一句话串起 3–5 个规模数字，数字 #C7000A 加粗、比正文大 2pt，其余 #333333 加粗，用「·」分隔；放在时间轴或图表下方做总结，例：「线上：约 120 名用户 · 300 个项目 · 1500 次调用」
- **图表样式**：用 PowerPoint 原生图表；删网格线或改 0.5pt #D9D9D9；图例放图表上方；必须标单位
- **结论与来源**：每张图上方一句结论（10.5pt 加粗）；页脚注明数据来源和统计时间，如「数据来源：xxx，截至 2026.09」
- **数据真实性**：只用提供或实测的数据，不编造。没有数据时用占位数值，图表右上角标「示意数据」

### C6 · 重点突出文本

- **位置和数量**：标题正下方，横跨整个内容区；按需使用，不要求每页都有，每页最多 1 个
- **左侧标签**：宽 2.0 cm 的窄矩形，高度与右侧一致，#C7000A 底；白色 12pt 加粗，水平垂直居中；2–4 字（如「核心观点」「关键数据」「背景」），4 字时分两行
- **右侧正文区**：与标签紧贴无空隙，#E7E6E6 底；12pt #333333，1–2 行，≤80 字；关键短语可加粗或标红
- **分工**：标题写结论，这里写支撑结论的关键依据、数据或前提，不复述标题

**变体**：同一种用多了显单调时换用，位置和数量限制同上（闭环条例外，见表），选哪种由内容决定。标准样式加下列六种，共七种强调样式。

| 变体 | 形态 | 适用 |
|---|---|---|
| 指标卡 | 横排 2–4 张 C5 指标卡 | 量化结论 |
| 推导条 | ①→②→③ 三个 #F2F2F2 块横排，#C7000A 箭头串联，结论块文字标红 | 现象→归因→结论 |
| 引语块 | 左侧 3pt #C7000A 竖线 + #F2F2F2 底，句首 #C7000A 大号引号，一句 14pt 加粗判断 | 核心论断、最终建议 |
| 标签云 | 10pt 直角小标签密排，#F2F2F2 底黑字，重点标签 #C7000A 底白字 | 能力罗列、边界界定 |
| 双色对照条 | 一条横条左右等分，左 #C7000A 底白字、右 #D9D9D9 底 #333333 字，各写半句结论 | 二元对比 |
| 闭环条 | 一条浅红底横条，「闭环：A → B → C → D」，#C7000A 箭头，末项标红；放在内容区**底部**横跨全宽 | 持续迭代、反馈回路的一句话总结 |

### C7 · 时间轴

- **主轴**：默认横向，2pt #A6A6A6 直线；尚未到来的规划段用虚线
- **节点**：直径 0.35 cm 的圆。已完成 #A6A6A6 实心；当前 #C7000A 实心，对应文字红色加粗；规划中白底 #A6A6A6 边框
- **文字**：时间标签在主轴上方，10pt 加粗；事件说明在主轴下方，10pt，≤2 行
- **数量和间距**：3–8 个节点，等间距；只有要强调时间跨度时才按实际时长排
- **日期格式**：全篇统一——年 2026，季度 2026Q3，月 2026.09
- **阶段说明**：要展开时在主轴下方放 C3 样式的阶段卡片，与节点上下对齐

### 编号标注（范式五用）

直径 0.45 cm 的圆，#C7000A 底，白色 9pt 加粗数字，放在被说明元素的右上角。图上编号与说明编号一一对应，每页 ≤6 个。

### C8 · 特性卡

- **结构**：一排 3–5 张等宽卡片，自上而下：C4 图标（约 1.6 cm，每个图标一处 #C7000A 点缀）→ 特性名 13.5pt 加粗居中 → 「**关键词：**说明」2–3 行 → 0.5pt #BFBFBF 分隔线 → 结果行
- **结果行**：每张卡一个可量化结果，数字 #C7000A 加粗放大，其余 #333333 加粗，1–2 行居中
- **外观**：#F2F2F2 底，直角；卡片等宽等高、顶端对齐
- **适用**：并列的能力、特性、举措，且每项都有线上数据或代码事实撑着；没有结果数字的用 C3

### C9 · 编号要点

- **结构**：编号圆（同「编号标注」，可放大到 0.6 cm）+ 要点标题 11.5–12pt 加粗 + 1–3 行说明；多条之间可加 0.5pt 分隔线
- **适用**：范式五右侧的编号说明、「下一步」做法列表、需求清单

### C10 · 回路图

- **结构**：3–4 个节点盒（图标 + 1–2 行文字）首尾相接，节点之间 1.5–2pt #C7000A 弯箭头（实心箭头），回路中心放回路名 13pt #C7000A 加粗
- **适用**：持续迭代、反馈闭环；只表达顺序不表达回路时用 C6 推导条

### C11 · 标签标题

- **结构**：#C7000A 胶囊标签（2–4 字，白色 9.5pt 加粗）紧贴一个 13pt 加粗标题
- **适用**：标明区块性质，如「下一步」「风险」「结论」；每页 ≤2 个

### C12 · 英雄数字卡

- **结构**：指标名（12pt 加粗）+ 右上涨跌徽标 → 一个 60–72pt 的大数字（#C7000A）→ 1–2 行解释 → 底部迷你趋势线（无坐标轴，首尾标值，可挂一条引线标注）
- **适用**：一页只讲一个数字结论；和普通指标卡的区别是只有一个焦点
- **注意**：大数字的文本框高度要盖住整行行高（72pt 约 3 cm），否则 QuickLook 会把字挤到下面的说明上

### C13 · 哑铃图

- **结构**：每行一项，灰点（前，#A6A6A6）— 红点（后，#C7000A），中间 3pt #BFBFBF 连线；数值标在点外侧；右列是涨跌徽标；顶部共用刻度
- **适用**：3–8 项的前后对比，替代一排前后对比指标卡；重点行名标红

### C14 · 瀑布图

- **结构**：起点柱（#BFBFBF）→ 各分项浮动柱（下降 #E6A5A8 / 上升 #D9D9D9）→ 终点柱（#C7000A），柱间虚线衔接，柱顶标数值
- **适用**：回答「变化从哪里来」；**必须有分项的真实数据**，拆不出分项就不用

### C15 · 哈维球矩阵

- **结构**：行是能力、列是方案，单元格用哈维球表示 0–4 档（○ ◔ ◑ ◕ ●）；重点列整列浅红底、表头标红；底部图例
- **适用**：多方案能力对比，比 ✓ / × 更细

### C16 · 四象限

- **结构**：两轴 + 虚线中线 + 四个象限名；重点象限浅红底；重点事项红点，其余灰点；轴名写在轴端
- **适用**：定位、优先级判断（价值 × 紧迫度、投入 × 产出）

### C17 · 指标拆解树

- **结构**：从左到右逐层拆：节点是「名称 / 数值 / 涨跌徽标」；父子之间折线连接，拐点上标运算（× / +）；最大杠杆那条路径节点红框、连线标红；底部一句结论
- **适用**：范式九 · 拆解

### C18 · 泳道路标图

- **结构**：横轴是时间段，每条泳道一个工作流；条带：已完成 #BFBFBF 深字、进行中 #C7000A 白字、规划中白底灰虚线；里程碑红色菱形；「今天」一条红竖线，标签放在泳道底部
- **适用**：多条工作流并行的计划；单条线用 C7

### C20 · 箭头流程

- **结构**：首尾相扣的箭头块：已完成 #BFBFBF 深字、当前 #C7000A 白字、未开始 #ECEDEF 灰字；下方每步 1–2 行说明
- **适用**：3–6 步的阶段或流程，比圆角卡 + 三角更整体

### C22 · 鱼骨图

- **结构**：右侧问题（红底）、脊骨向右；类别骨上下交替斜出，类别标签在骨端；子因横线挂在骨上，文字右对齐；重点类别红底红骨，重点子因红字
- **几何**：子因横线长度 = 列距 − 24 px，同一高度上左邻骨正好在一个列距之外，不会压线；每根骨 2–3 个子因
- **适用**：范式八 · 归因

### C23 · 漏斗图

- **结构**：左列环节名、中间梯形（宽度按数量等比，最窄不小于 20%）、右列段间转化率；转化率最低的一段用浅红胶囊标出；梯形用 #A6A6A6 → #E6E6E6 渐变，字一律深色
- **适用**：范式十 · 转化

### C24 · 子弹图

- **结构**：每行一条：差 / 中 / 良三档灰区间（#D9D9D9 / #E6E6E6 / #F2F2F2）+ #8C8C8C 实际值细条 + 红色目标刻度；右列「实际 / 目标」和差距徽标，达标用状态点；未达标行名标红；底部图例
- **适用**：范式十一 · 评估（达成）

### C25 · 风险矩阵

- **结构**：5×5 格（可能性 × 影响），按乘积分四档上色（极高 #C7000A / 高 #E6A5A8 / 中 #FBECED / 低 #F2F2F2）；风险用白底编号圈标在格中，同格自动错开；右侧应对清单与编号一一对应（风险名、等级胶囊、应对、负责人）
- **适用**：范式十一 · 评估（风险）

### C26 · 战略屋

- **结构**：屋顶（愿景，红底白字）→ 横梁（年度目标，#D9D9D9 深字）→ 3–5 根支柱（名称 + 3 条要点，重点支柱浅红）→ 1–2 层地基（底座能力、组织机制）
- **适用**：范式十二 · 蓝图

### C27 · 成熟度阶梯

- **结构**：台阶逐级升高；已达到 #BFBFBF 带、当前红色带 + 浅红体、未达到虚线框；当前台阶上方「当前位置」胶囊 + 小三角，目标台阶插红旗
- **适用**：范式十二 · 蓝图（能力分级、演进路径）

### C28 · 中心辐射图

- **结构**：中心红圆是我方，周围 4–8 个伙伴 / 角色框，连线上写往来内容（竖线太短时文字放在线旁）；重点伙伴红框红线，可标双向
- **适用**：范式十三 · 生态

### C29 · 工序流程图（人机分工）

讲「事情怎么一步步做成、谁做什么」：中间一条主干是工序，左泳道写人在哪一步做什么判断，右泳道写系统在这一步提供什么能力。落 pptx 用排版引擎 `process_flow`。

- **主干**：投入梯形 → 带编号的工序框（①②③…自动编号；重点工序浅红底）→ 产物节点（阶段成果，红色外框 + 灰色内框）→ 产出梯形；关口工序到产出的线上写「通过」
- **回路**：返工回路用红虚线，从关口工序左侧退回指定工序；说明自动放在两道工序之间的空档，不和引线同行
- **泳道**：泳道头 = 图标 + 名称；左侧确认点 = 红色 ✓ + 两行文字，虚线引线止于回路通道外侧的圆点；右侧能力 = 粗体名 + 灰色说明，虚线引线从工序框右边连出
- **底座**：底部技术栈条 + 1–2 行说明
- **限额**：工序 ≤8 道；确认点文字 ≤8 字；有回路时左泳道和主干之间留回路通道
- **适用**：范式十四 · 流程

## 五、排版范式（十四种）

### 选择

先看内容属于哪种逻辑关系，再按对应范式的默认布局排。

| 内容特征 | 范式 |
|---|---|
| 两个及以上方案、产品、竞品做比较 | 一 · 对比 |
| 3–6 个同级要点、能力、举措 | 二 · 并列 |
| 先讲问题、挑战、痛点，再给方案 | 三 · 推导 |
| 年份、阶段、里程碑、路标 | 四 · 时间 |
| 系统、软件、方案或组织的结构 | 五 · 架构 |
| 用数据说明趋势或差异 | 六 · 图表 |
| 同时符合以上两种 | 七 · 组合 |
| 一个问题，要找根因并量化各类占比 | 八 · 归因 |
| 一个目标指标，要拆到驱动因素、找最大杠杆 | 九 · 拆解 |
| 有先后的环节，每一环都有流失 | 十 · 转化 |

## 六、每页构成

- **必须包含**：标题；至少一个视觉主体（C1、C2、C5、C7 或 C4 示意图）；至少一处文字解读（C3、C6 或图表上方的结论句）
- **上限**：内容区 2–4 个区块（C6 不计），正文合计 ≤400 字
- **紧凑饱满**：区块间统一 0.3 cm；内容区底部空白 ≤2 cm；并排区块等高、顶端对齐
- **阅读顺序**：从上到下、从左到右

## 七、文案

- 短句、动宾结构，能用数字的先写数字；一条只讲一件事
- 术语全篇统一：首次出现中英对照，如「强化学习（RL）」，之后只用一种写法
- 中文标点一律全角

## 八、非内容页

公司有模板就沿用；没有时：

- **封面**：主标题 28pt 加粗 #C7000A；副标题 16pt 黑；部门和日期 12pt #595959
- **目录页、章节页**：章节号和章节名 24pt；当前章节 #C7000A，其余 #A6A6A6
- **总结页**：上方 C6 写总体结论，下方按范式二列 3–5 条结论和下一步计划，计划写明负责人和时间

## 九、生图风格句

AI 生图看不到本文件，所以每段生图提示词末尾都要原样附上「通用」句，画 C1、C4、C7 时再追加对应一句。

- **通用**：扁平矢量风格，白色背景，直角矩形，无阴影、无渐变、无 3D、无照片元素；浅色系，只用这些颜色：#C7000A 作强调，#A6A6A6、#BFBFBF 作灰阶，#F2F2F2、#D9D9D9、#E6E6E6 作浅灰底，#333333 深灰文字；不用黑色和深灰色块；画面里只保留短标签，不放长句。
- **C1 架构图**：自上而下分层，每层左侧是 #D9D9D9 底的竖排层名条，右侧是白底、0.75pt #BFBFBF 细边框的直角模块，同一行等宽铺满、各层左右对齐；重点模块用 #C7000A 边框。
- **C4 示意图**：简约线性图标风格，线宽统一，主体中灰，最多一处红色点缀。
- **C7 时间轴**：横向时间轴，#A6A6A6 主轴，节点为小圆点：已完成中灰实心、当前红色实心、规划中空心，规划段用虚线。
- **C29 工序流程图**：纵向主干，上方投入梯形、中间编号工序框、下方产出梯形；左侧一列人物图标泳道带红色对勾确认点，右侧一列齿轮图标泳道写系统能力，虚线引线连到工序；返工回路用红色虚线。

- [ ] 每段生图提示词都附了第九节的风格句
