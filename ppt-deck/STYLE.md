# 默认样式规范

16:9。用户另有要求时以用户的为准。

## 标题

| 项 | 规格 |
|---|---|
| 字体 | 微软雅黑 |
| 字号 | 20 |
| 颜色 | `#c7000a` |
| 内容 | 一句**高度总结全页内容且有明确观点**的话 |

### 范例

> 缓存命中率是响应延迟的主导因素，预热策略与淘汰算法是优化重点

> 存储业务趋势：单集群规模／总容量双增长，冷热分层／弹性扩容／统一元数据成共性需求

> 边缘推理：围绕典型场景依托算子融合、量化压缩等方案持续降低端到端时延

三例的共同结构：**给出判断 + 指明关键因素**。不是罗列事实，而是把事实压成一句可被复述的结论。

## 正文

| 项 | 规格 |
|---|---|
| 字体 | 微软雅黑 |
| 字号 | 10–12 |
| 颜色 | 黑色 |
| 密度 | 各元素之间布局紧凑，每页内容饱满 |
| 强调 | 重点文字加粗，或标 `#c7000a` |

## 内容形式（六种）

**每页必须含图示和文字块**，其余按需组合。

### 1 · 分层架构图
从上到下多层，左侧竖排层级名侧边栏，右侧模块整齐排列。密度紧凑。

### 2 · 表格
一般 3–4 列。**字段行背景采用其他颜色，其余行白底**。

### 3 · 文字块
浅灰底、无边框。带标题，标题为**黑色微软雅黑加粗居中**。正文要做逻辑拆分、分点阐述；重点文字加粗或标 `#c7000a`。**适当时在块内绘制图片辅助说明**。

### 4 · 图示
简约大方的插图风格。

### 5 · 图表
仪表盘的组合，用于对数字做统计。柱状、折线、雷达等亦可，按数据性质选。

### 6 · 时间轴
格式不限。

## 排版范式（七种）

| 范式 | 用法 |
|---|---|
| 一 · 对比 | 强调差异或共同点 |
| 二 · 并列 | 分点描述概念 |
| 三 · 推导 | 由挑战、痛点推出方案 |
| 四 · 时间 | 按时间打开步骤或阶段 |
| 五 · 架构 | 一边架构图，一边序号拆解说明 |
| 六 · 组合 | 时间＋推导＋并列的混合 |
| 七 · 图表 | 以图表为主论证，配标注 |

## 强调块样式库（六种，跨页轮换）

内容形式之外的补充。用于承载全页最需被记住的那句判断。

| 样式 | 形态 | 适用 |
|---|---|---|
| A · 指标卡 | 超大号数字 + 一行说明，横排 2–4 个 | 量化结论 |
| B · 推导条 | ①→②→③ 横向递进，箭头串联 | 现象→归因→结论 |
| C · 引语块 | 大号引号包裹一句判断，左侧竖线 | 核心论断、最终建议 |
| D · 标签云 | 关键词做成小标签密排 | 能力罗列、边界界定 |
| E · 双色对照条 | 一条横条左右两半异色，各写一半结论 | 二元对比 |
| F · 色块强调 | 窄色块 + 等高说明块 | 补充说明，不宜作主角 |

**同一份材料里不要连续两页用同一种。**

## 设计要点备查

每页稿末附一张表，列出制作时需注意的规格：形状语言、色彩用法、视觉重心、块间关系。只写影响表意的项，不写通用排版常识。
