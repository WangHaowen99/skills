# 默认样式规范

16:9。用户另有要求时以用户的为准。

## 字体与配色

| 元素 | 规格 |
|---|---|
| 标题 | 微软雅黑 20pt，`#c7000a` |
| 正文 | 微软雅黑 10–12pt，黑色 |
| 强调色 | `#c7000a`，用于关键数字、判断性结论、视觉焦点 |
| 文字块底 | 浅灰，无边框 |
| 整体密度 | 紧凑饱满，块间距小，四周留白窄 |

## 内容形式（七种）

每页必须含**图示**和**文字块**，其余按需组合。

1. **分层架构图**——从上到下多层。左侧竖排层级名侧边栏，右侧模块整齐排列。密度紧凑
2. **表格**——3–4 列。表头行填色，数据行白底
3. **文字块**——浅灰底无边框，带加粗居中标题，内容分点。重点加粗或标 `#c7000a`
4. **图示**——简约插图风格
5. **图表**——柱状／折线／雷达／仪表盘，用于量化对比
6. **强调块**——见下方样式库
7. **时间轴**——格式不限

## 排版范式（七种）

| 范式 | 用法 |
|---|---|
| 一 · 对比 | 强调差异或共同点 |
| 二 · 并列 | 分点描述概念 |
| 三 · 推导 | 由挑战、痛点推出方案 |
| 四 · 时间 | 按时间打开步骤或阶段 |
| 五 · 架构 | 一边架构图，一边序号拆解说明 |
| 六 · 组合 | 时间＋推导＋并列的混合 |
| 七 · 图表 | 以图表为主论证，配标注 |

## 强调样式库（六种，跨页轮换）

| 样式 | 形态 | 适用 |
|---|---|---|
| A · 指标卡 | 超大号数字 + 一行说明，横排 2–4 个 | 量化结论 |
| B · 推导条 | ①→②→③ 横向递进，箭头串联 | 现象→归因→结论 |
| C · 引语块 | 大号引号包裹一句判断，左侧竖线 | 核心论断、设计原则 |
| D · 标签云 | 关键词做成小标签密排 | 能力罗列、风险项 |
| E · 双色对照条 | 一条横条左右两半异色，各写一半结论 | 二元对比 |
| F · 色块强调 | 窄色块 + 等高说明块 | 补充说明，不宜作主角 |

## 设计要点备查

每页稿末附一张表，列出制作时需注意的规格：形状语言、色彩用法、视觉重心、块间关系。只写影响表意的项，不写通用排版常识。
