# 默认样式规范

用户另有要求时以用户的为准。

默认按**阅读型**材料设计（发送阅读、打印、近距离投屏）。**宣讲型**（大会场投屏）：正文 ≥14pt，每页内容区 2–3 个区块，其余照旧。

## 一、页面框架

| 项 | 规定 |
|---|---|
| 画布 | 16:9 宽屏，33.87 × 19.05 cm |
| 页边距 | 左右 1.0 cm，上 0.6 cm，下 0.8 cm |
| 标题区 | 距顶 0.6 cm 起，高 1.6 cm；左对齐，文本框顶端对齐；每页位置固定；标题下不加分隔线 |
| 内容区 | 标题区下方 0.3 cm 起，至距底 1.0 cm 止，约 31.9 × 15.5 cm |
| 页脚 | 左下数据来源／注释，右下页码；有密级要求时放页脚中间 |
| 区块间距 | 全页统一 0.3 cm |
| 块内边距 | 左右 0.2 cm，上下 0.15 cm |

## 二、字体、字号、颜色

### 字体

中文微软雅黑，西文和数字 Arial。PowerPoint 字体对话框里「西文字体」「中文字体」两项都要设。

### 字号

| 元素 | 字号 | 样式 | 颜色 |
|---|---|---|---|
| 页面标题 | 20pt | 加粗 | #C7000A |
| 重点突出文本 · 左侧标签 | 12pt | 加粗 | 白 |
| 重点突出文本 · 右侧正文 | 12pt | 常规，关键词加粗 | 黑 |
| 区块标题 | 12pt | 加粗，居中 | 黑 |
| 正文 | 11pt（可在 10.5–12pt 间调） | 常规 | 黑 |
| 表头 | 11pt | 加粗 | 白 |
| 表格内容 | 10.5pt | 常规 | 黑 |
| 架构图模块、时间轴说明 | 10pt | 常规 | 黑 |
| 指标卡数字 | 24pt | 加粗 | #C7000A |
| 图表坐标轴、数据标签 | 9pt | 常规 | #595959 |
| 脚注、数据来源、页码 | 8pt | 常规 | #595959 |

除图表标注和脚注外，不小于 10pt。

### 色板

全篇只用下列颜色。

| 色值 | 用途 |
|---|---|
| #C7000A | 标题、红色标签底、强调文字、重点模块边框、时间轴当前节点 |
| #000000 | 正文、架构图边框 |
| #404040 | 表头底、图标主体 |
| #595959 | 次要文字、坐标轴、普通箭头 |
| #A6A6A6 | 时间轴主轴、图表辅助系列 |
| #BFBFBF | 表格框线、分隔线 |
| #D9D9D9 | 架构图层名侧边栏底 |
| #E7E6E6 | 重点突出文本右侧底 |
| #F2F2F2 | 文字块、表格首列、指标卡底 |

图表系列按 #C7000A → #595959 → #A6A6A6 → #E6A5A8 取色；重点系列用红，其余用灰。

### 强调

- 加粗：关键词、要点小标题
- #C7000A：关键数字、结论性短语
- 除标题和红色标签外，每页标红 ≤5 处，每个文字块 ≤2 处
- 不用下划线、斜体、荧光底色

### 形状与线条

- 一律直角；不加阴影、渐变、3D、发光
- 架构图边框 0.75pt 黑；表格框线、分隔线 0.5pt #BFBFBF；普通箭头 1pt #595959；重点路径箭头 1.5pt #C7000A
- 最终 pptx 里全部内容可编辑（文本框、形状、原生表格和图表），不直接贴位图；AI 生成的图可用 `image-to-pptx` 复刻成原生形状

## 三、标题

「必须有观点」见 SKILL.md 铁律，这里只管格式。

| 项 | 规定 |
|---|---|
| 样式 | 微软雅黑 20pt 加粗 #C7000A |
| 句式 | 「主题：观点」，主题 2–8 字 |
| 长度 | ≤40 字（英文、数字两个算一个字），最多两行；超长改写，不缩字号 |
| 观点数 | 一页一个核心观点；有两个时须是因果或递进关系 |
| 依据 | 标题里的每个判断都能在本页正文找到依据 |
| 禁用 | 没有对象、没有数字的空泛词：赋能、全面提升、持续优化 |

### 范例

- ✓ `Agentic RL：训练决定Agent效果上限，超长序列优化与并行调度决定训练性能`
- ✓ `多模态趋势：头部客户单任务规模与总空间双增长，长序列/RL/统一多模态成共性需求`
- ✗ `自动驾驶：围绕ADS等重点客户依托图下沉、算子融合等方案持续优化模型性能`——只写做了什么，没有结论
- ✓ `自动驾驶：图下沉+算子融合使ADS模型端到端时延下降XX%，已在N家重点客户落地`——XX、N 用真实数据

## 四、内容组件

稿里引用组件时写编号（C1–C7），样式按本节，不在稿里重复。

### C1 · 分层架构图

- **结构**：自上而下 3–6 层，每层一行；左为层名侧边栏，右为模块区
- **侧边栏**：宽 0.9 cm，各层同宽，高度与本层模块区一致；#D9D9D9 底；层名 10.5pt 黑色加粗，文字方向「竖排」，2–6 个汉字。尽量不用英文层名，必须用时设「所有文字旋转 270°」
- **模块**：直角矩形，白底，0.75pt 黑框；文字 10pt 黑色，水平垂直居中，≤8 字或 2 行
- **间距与对齐**：模块间、层间都留 0.15 cm；同层模块等高等宽；各层左右边界对齐；每层 ≤8 个模块
- **重点模块**：本方案新增或重点说明的，边框改 1.5pt #C7000A、文字加粗；不超过模块总数的 1/4
- **分组**：层内分组用 #F2F2F2 底、无边框的组框包住，组名 9pt 加粗置于组框顶部
- **跨层模块**：纵向拉长贯穿对应各层，放模块区最右侧
- **箭头**：默认不画；要表达数据流向时用 1pt #595959 直线箭头

### C2 · 表格

- **规模**：3–4 列，数据行 ≤8 行
- **表头**：#404040 底，白色 11pt 加粗，居中
- **数据行**：白底，10.5pt 黑色；对比表的首列是「对比维度」，#F2F2F2 底加粗
- **框线**：所有单元格 0.5pt #BFBFBF
- **对齐**：文字左对齐；数字、✓/×、高/中/低等短值居中；一律垂直居中
- **强调**：关键单元格文字 #C7000A 加粗，每表 ≤3 处；不用整行底色强调

### C3 · 文字块

- **外观**：#F2F2F2 底，无边框，直角
- **块标题**：12pt 黑色加粗，居中，置于块顶，与正文间距 0.15 cm
- **正文**：11pt 黑色，左对齐，1.1 倍行距；一级要点用 #C7000A 小方块「■」，二级用黑色「–」，最多两级
- **条数和写法**：每块 3–5 条，每条 ≤2 行；统一写成「**关键词：**说明」
- **配图**：讲流程或结构时，块内可放 1 个 C4 示意图，放在块标题下方或正文右侧，高度 ≤块高 1/3
- **并排**：多块并排时等宽等高，标题在同一水平线上

### C4 · 示意图与图标

- **图标**：优先用 PowerPoint「插入 → 图标」里同一套线性图标；主体 #404040，每个图标最多一处 #C7000A 点缀
- **示意图**：用矩形、圆、箭头、连接线等基本形状拼成
- **禁用**：照片、3D、渐变、emoji、卡通人物、网络剪贴画、不同风格图标混用

### C5 · 数据图表与指标卡

**按用途选图**

| 要表达的 | 用 |
|---|---|
| 单个关键数字 | 指标卡 |
| 类别比较 | 柱状图或条形图 |
| 变化趋势 | 折线图 |
| 构成比例（≤5 类） | 堆叠条形图或环形图 |
| 多维评估（4–6 维，且有对照对象） | 雷达图 |
| 完成率、达成率 | 半圆仪表盘，每页 ≤3 个 |

- **指标卡**：#F2F2F2 底；数字 24pt #C7000A 加粗，单位 12pt，说明 10pt，同比／环比 9pt；多张并排等宽
- **前后对比指标卡**：一行「旧值 → 新值」，旧值 #404040 加粗，新值 #C7000A 加粗、比旧值大约 1.2 倍，单位与新值同色；说明一行放在下方。适合「改进前后」类结论，同页 2–4 张竖排或横排
- **统计条**：一句话串起 3–5 个规模数字，数字 #C7000A 加粗、比正文大 2pt，其余黑色加粗，用「·」分隔；放在时间轴或图表下方做总结，例：「线上：约 120 名用户 · 300 个项目 · 1500 次调用」
- **图表样式**：用 PowerPoint 原生图表；删网格线或改 0.5pt #D9D9D9；图例放图表上方；必须标单位
- **结论与来源**：每张图上方一句结论（10.5pt 加粗）；页脚注明数据来源和统计时间，如「数据来源：xxx，截至 2026.09」
- **数据真实性**：只用提供或实测的数据，不编造。没有数据时用占位数值，图表右上角标「示意数据」

### C6 · 重点突出文本

- **位置和数量**：标题正下方，横跨整个内容区；按需使用，不要求每页都有，每页最多 1 个
- **左侧标签**：宽 2.0 cm 的窄矩形，高度与右侧一致，#C7000A 底；白色 12pt 加粗，水平垂直居中；2–4 字（如「核心观点」「关键数据」「背景」），4 字时分两行
- **右侧正文区**：与标签紧贴无空隙，#E7E6E6 底；12pt 黑色，1–2 行，≤80 字；关键短语可加粗或标红
- **分工**：标题写结论，这里写支撑结论的关键依据、数据或前提，不复述标题

**变体**：同一种用多了显单调时换用，位置和数量限制同上（闭环条例外，见表），选哪种由内容决定。标准样式加下列六种，共七种强调样式。

| 变体 | 形态 | 适用 |
|---|---|---|
| 指标卡 | 横排 2–4 张 C5 指标卡 | 量化结论 |
| 推导条 | ①→②→③ 三个 #F2F2F2 块横排，#C7000A 箭头串联，结论块文字标红 | 现象→归因→结论 |
| 引语块 | 左侧 3pt #C7000A 竖线 + #F2F2F2 底，句首 #C7000A 大号引号，一句 14pt 加粗判断 | 核心论断、最终建议 |
| 标签云 | 10pt 直角小标签密排，#F2F2F2 底黑字，重点标签 #C7000A 底白字 | 能力罗列、边界界定 |
| 双色对照条 | 一条横条左右等分，左 #C7000A 底白字、右 #404040 底白字，各写半句结论 | 二元对比 |
| 闭环条 | 一条浅红底横条，「闭环：A → B → C → D」，#C7000A 箭头，末项标红；放在内容区**底部**横跨全宽 | 持续迭代、反馈回路的一句话总结 |

### C7 · 时间轴

- **主轴**：默认横向，2pt #A6A6A6 直线；尚未到来的规划段用虚线
- **节点**：直径 0.35 cm 的圆。已完成 #595959 实心；当前 #C7000A 实心，对应文字红色加粗；规划中白底 #A6A6A6 边框
- **文字**：时间标签在主轴上方，10pt 加粗；事件说明在主轴下方，10pt，≤2 行
- **数量和间距**：3–8 个节点，等间距；只有要强调时间跨度时才按实际时长排
- **日期格式**：全篇统一——年 2026，季度 2026Q3，月 2026.09
- **阶段说明**：要展开时在主轴下方放 C3 样式的阶段卡片，与节点上下对齐

### 编号标注（范式五用）

直径 0.45 cm 的圆，#C7000A 底，白色 9pt 加粗数字，放在被说明元素的右上角。图上编号与说明编号一一对应，每页 ≤6 个。

### C8 · 特性卡

- **结构**：一排 3–5 张等宽卡片，自上而下：C4 图标（约 1.6 cm，每个图标一处 #C7000A 点缀）→ 特性名 13.5pt 加粗居中 → 「**关键词：**说明」2–3 行 → 0.5pt #BFBFBF 分隔线 → 结果行
- **结果行**：每张卡一个可量化结果，数字 #C7000A 加粗放大，其余黑色加粗，1–2 行居中
- **外观**：#F2F2F2 底，直角；卡片等宽等高、顶端对齐
- **适用**：并列的能力、特性、举措，且每项都有线上数据或代码事实撑着；没有结果数字的用 C3

### C9 · 编号要点

- **结构**：编号圆（同「编号标注」，可放大到 0.6 cm）+ 要点标题 11.5–12pt 加粗 + 1–3 行说明；多条之间可加 0.5pt 分隔线
- **适用**：范式五右侧的编号说明、「下一步」做法列表、需求清单

### C10 · 回路图

- **结构**：3–4 个节点盒（图标 + 1–2 行文字）首尾相接，节点之间 1.5–2pt #C7000A 弯箭头（实心箭头），回路中心放回路名 13pt #C7000A 加粗
- **适用**：持续迭代、反馈闭环；只表达顺序不表达回路时用 C6 推导条

### C11 · 标签标题

- **结构**：#C7000A 胶囊标签（2–4 字，白色 9.5pt 加粗）紧贴一个 13pt 加粗标题
- **适用**：标明区块性质，如「下一步」「风险」「结论」；每页 ≤2 个

### 组件实现（落 pptx）

本节组件在 `image-to-pptx` skill 的 `tools/components.py` 里有同编号实现，设计稿定稿后可直接按编号搭成可编辑 pptx。先 `use_theme(STYLE)`，配色和直角即按本规范；不切换时是「复刻风」（圆角、浅红强调），用于按图复刻。

| 编号 | 函数 |
|---|---|
| C1 分层架构图 | `arch_layer`（层名侧栏 + 模块区）、`module_cell`、`fanout`（分发连线）、`bi_arrow` |
| C2 表格 | `grouped_table`（原生表格，首列分组合并、重点行底色） |
| C4 图标 | `icon_lib` 77 个线性图标，`ic_xxx(sh, cx, cy, 尺寸, 主体色)` |
| C5 图表与指标卡 | `line_chart_card`、`metric_card` + `ba_parts`（前后对比）、`stat_line`（统计条） |
| C6 强调变体 | `step_chain`（推导条）、`flow_band`（闭环条） |
| C7 时间轴 | `milestone_timeline`（含阶段卡、状态带） |
| C8 特性卡 | `feature_row` |
| C9 编号要点 | `numbered_item`；编号标注用 `numc` |
| C10 回路图 | `cycle_diagram` + `cycle_arrows` |
| C11 标签标题 | `tag_title` |

## 五、排版范式（七种）

### 选择

先看内容属于哪种逻辑关系，再按对应范式的默认布局排。

| 内容特征 | 范式 |
|---|---|
| 两个及以上方案、产品、竞品做比较 | 一 · 对比 |
| 3–6 个同级要点、能力、举措 | 二 · 并列 |
| 先讲问题、挑战、痛点，再给方案 | 三 · 推导 |
| 年份、阶段、里程碑、路标 | 四 · 时间 |
| 系统、软件、方案或组织的结构 | 五 · 架构 |
| 用数据说明趋势或差异 | 六 · 图表 |
| 同时符合以上两种 | 七 · 组合 |

### 默认布局

| 范式 | 布局 |
|---|---|
| 一 · 对比 | 两方：左右两栏 1:1，按相同维度、相同顺序逐项对应，差异点标红。三方以上或维度多：改用 C2 对比表，首列写维度。结论放底部，用 C6 或窄文字块 |
| 二 · 并列 | 3–4 项排成等宽列；4–6 项排成 2×2 或 2×3 网格。每个单元是 C4 图标 + 块标题 + 2–4 条要点，结构一致、字数相近 |
| 三 · 推导 | 左中右三栏：挑战／痛点（约 35%）→ 方案（约 35%）→ 收益（约 30%），栏间 #C7000A 箭头。痛点与方案条目一一对应、同行对齐；收益栏关键数字标红 |
| 四 · 时间 | 上方 C7 时间轴（约占内容区高度 1/3），下方阶段卡片与节点对齐；或改用 C2 阶段表，列为「阶段／时间／目标／关键动作」 |
| 五 · 架构 | 左约 60% 放 C1 架构图（或组织、方案架构图）；右约 40% 放编号说明，每条「编号 + 关键词 + 1–2 行说明」，按编号顺序排 |
| 六 · 图表 | 左约 60% 放 C5 图表，右约 40% 放解读（一句结论 + 2–4 条原因或启示）；或上方 3–4 张指标卡，下方放图表 |
| 七 · 组合 | 一页最多组合 2 种范式。上下切分为 40% / 60%，左右切分为 5:5 或 6:4；上方或左方放总览，下方或右方放展开。例：上方时间轴 + 下方推导；左侧架构图 + 右侧对比表 |

### 成品页型（有现成实现，可直接套）

都属于范式七 · 组合，排版已在实际汇报里验证过：

| 页型 | 布局 | 组件 | 适用 |
|---|---|---|---|
| A · 总览页 | 上部左右 5:4：左为 C5 折线图卡 + 3 张前后对比指标卡，右为 C7 时间轴 + 统计条；下部一排 5 张 C8 特性卡 | `overview_page` 一次搭完 | 阶段成果汇报：一个核心趋势 + 几个关键数字 + 里程碑 + 特性清单 |
| B · 主次两栏页 | 左约 62% 为主：C6 推导条（3 步）+ C2 分组表格；右约 38% 为次：精简 C1（3–4 层）+ C11 + C9；底部闭环条 | 逐组件搭 | 「成果 + 支撑手段」：左讲做成了什么，右讲靠什么做到、下一步 |
| C · 三栏 + 底表页 | 左 C9 编号要点卡、中 C1 架构图、右 C10 回路图；底部横跨 C2 分组表格 | 逐组件搭 | 「需求 → 架构 → 生态」：一页讲清为什么、怎么做、怎么闭环 |

## 六、每页构成

- **必须包含**：标题；至少一个视觉主体（C1、C2、C5、C7 或 C4 示意图）；至少一处文字解读（C3、C6 或图表上方的结论句）
- **上限**：内容区 2–4 个区块（C6 不计），正文合计 ≤400 字
- **紧凑饱满**：区块间统一 0.3 cm；内容区底部空白 ≤2 cm；并排区块等高、顶端对齐
